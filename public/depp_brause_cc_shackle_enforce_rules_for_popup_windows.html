    (depp.brause.cc) shackle: Enforce rules for popup windows

    ROAM_REFS: https://depp.brause.cc/shackle/

    ** About

    shackle
    gives you the means to put an end to popped up buffers not behaving they way you'd like them to. By setting up simple rules you can for instance make Emacs always select help buffers for you or make everything reuse your currently selected window.
