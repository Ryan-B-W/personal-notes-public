    (ox-hugo.scripter.co) ox-hugo - Org to Hugo exporter

    ROAM_REFS: https://ox-hugo.scripter.co/
    • Org to Markdown for Hugo

    ox-hugo
    is an Org exporter backend that exports Org to Hugo-compatible Markdown (Blackfriday) and also generates the front-matter (in TOML or YAML format).

    The 

    ox-hugo
    backend extends from a parent backend 
    ox-blackfriday.el
    . The latter is the one that primarily does the Blackfriday-friendly Markdown content generation. The main job of 
    ox-hugo
    is to generate the front-matter for each exported content file, and then append that generated Markdown to it.

    There are, though, few functions that 

    ox-hugo.el
    overrides over those by 
    ox-blackfriday.el
    .

    See the Real World Examples section to quickly jump to sites generated using 

    ox-hugo
    and their Org sources.
