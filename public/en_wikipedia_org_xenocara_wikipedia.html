    (en.wikipedia.org) Xenocara - Wikipedia

    ROAM_REFS: https://en.wikipedia.org/wiki/Xenocara

    Xenocara is the OpenBSD build infrastructure for the project's customised X.Org Server that utilises a dedicated _x11 user by default to drop privileges and perform privilege separation in accordance to OpenBSD's "least privilege" policy.

    Until release 6.9, X.Org used imake but recent modularised versions have switched to GNU autotools. Xenocara uses BSD make and is designed to ease building and maintenance of modularised X.Org within the OpenBSD CVS tree. It first appeared with OpenBSD 4.2, released on 1 November 2007 (17 years ago) (2007-11-01); before that, OpenBSD had a different build system and repositories for X in CVS, which have since been completely retired in favour of Xenocara.

    Apart from X.Org, Xenocara builds several other projects, including window managers FVWM and cwm.
