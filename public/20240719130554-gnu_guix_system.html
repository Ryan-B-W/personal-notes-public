    A Linux distribution using the Guix package manager and repository.

    GNU Guix System or Guix System (previously known as GuixSD) is a rolling release, free and open source Linux distribution built around Guix, similar to how NixOS is built around Nix. It enables a declarative operating system configuration and allows system upgrades that the user can rollback. It uses the GNU Shepherd init system and the Linux-libre kernel, with the support of the GNU Hurd kernel under development. On February 3, 2015, the Free Software Foundation added the distribution to its list of endorsed free Linux distributions.
