    ** Windows 95 emulated in the browser via DOSBox

    Compact pre-installed Windows 95 hard disk image and AUTOEXEC.BAT file packaged for DOSBox, which runs in the browser thanks to hard work of contributors to Em-DOSBox, DOSBox, Emscripten, and web browser engines.

    This was originally hosted at win95.ajf.me, a site created by myself in May 2015, and inspired by the Internet Archive's DOS game emulation efforts (and using the same tech). Now it's on the Internet Archive itself. You can still go to that site if you want to know more about how this was done.
