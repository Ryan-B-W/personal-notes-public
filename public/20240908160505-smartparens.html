Smartparens

Emacs package for handling balancing of pairs. Similar to Paredit. Especially useful for editing Lisp code.

(github.com) Fuco1/smartparens: Minor mode for Emacs that deals with parens pairs and tries to be smart about it.   website

ROAM_REFS: https://github.com/Fuco1/smartparens

Smartparens is a minor mode for dealing with pairs in Emacs. It can automatically insert pairs: smartparens insert wrap, unwrap and rewrap pairs: smartparens wrapping expand and contract pairs: smartparens slurping navigate pairs: smartparens navigating and much more!
