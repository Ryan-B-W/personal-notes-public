    Emacs Lisp

    Emacs Lisp is a dialect of the Lisp family of programming languages used in the Emacs text editor. A Lisp-1—a Lisp with only one symbol namespace for variables and functions—with features in common more with Common Lisp than Scheme despite being a Lisp-1 like Scheme rather than a Lisp-2 like Common Lisp.
