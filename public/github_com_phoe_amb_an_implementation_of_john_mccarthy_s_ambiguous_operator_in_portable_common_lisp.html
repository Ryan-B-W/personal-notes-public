    (github.com) phoe/amb: An implementation of John McCarthy's ambiguous operator in portable Common Lisp.

    ROAM_REFS: https://github.com/phoe/amb
    • AMB

    This is an implementation of John McCarthy's ambiguous operator written in portable Common Lisp.

    The 

    amb
    operator implements a system which is capable of automatically searching for a set of values for variables (henceforth called ambiguous variables) for which a set of constraints is satisfied. The operator and its example use are described in detail in Structure and Interpretation of Computer Programs Chapter 4.3 (Nondeterministic Computing).

    See the manual and the SICP test cases for examples.
